# MAX Bot

Простой чат-бот для MAX Messenger на TypeScript.

## Стек

- Node.js
- TypeScript
- MAX Messenger Bot API

## Структура

```text
src/
└── bot.ts            # Основная логика и инициализация бота
certs/                # SSL-сертификаты для защищенного соединения
.env.example          # Пример конфигурационного файла
tsconfig.json         # Настройки компилятора TypeScript
package.json          # Зависимости и скрипты проекта
```

## Запуск локально

### Требования

Требуется Node.js:
- 18.20.2+ или 20.9+

### Настройка окружения

Создайте файл `.env` в корне проекта и добавьте ваш токен:

```env
BOT_TOKEN=токен_бота
```

### Запуск проекта

Установка зависимостей:
```bash
npm install
```

Запуск development-сервера:
```bash
npm run dev
```

## Функционал и команды

- `/start` — Бот отвечает приветствием.
- `/help` — Выводит руководство пользователя.
- `/about` — Показывает информацию о боте.
- `Открытие диалога` — Бот автоматически отправляет приветственное сообщение.

## Основные команды

```bash
npm install          # Установка всех зависимостей проекта
npm run dev          # Запуск бота в режиме разработки с hot-reload
```
