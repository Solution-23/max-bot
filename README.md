# MAX Bot

Простой чат-бот для MAX Messenger на TypeScript.

## Требования

- Node.js
- npm

## Установка

```bash
npm install

Создай .env:

BOT_TOKEN=токен_бота
Запуск
npm run dev


Команды
/start — бот отвечает приветствием.
Открытие диалога — бот отправляет приветственное сообщение.
Структура
src/
└── bot.ts

.env.example
package.json
tsconfig.json
README.md
